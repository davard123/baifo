# 念经板块 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 /nianjing/：用户自己看拼音念经，页面用本机语音识别跟上位置。

**Architecture:** 经文数据按部懒加载；`sutraAligner.js` 是 ScriptAligner.java 的 JS 移植（纯函数，可在 node 测）；`voiceEngine.js` 封装 vosk-browser（模型切块放 public，同源，拼成 blob URL 加载）和 iOS 的 webkitSpeechRecognition；页面 `NianjingPage.vue` 管模式与状态，竖屏单栏 / 横屏双栏用 CSS 媒体查询 `orientation`。

**Tech Stack:** Vue 3 + vue-router + Vite；vosk-browser；pinyin-pro（只在「听我念」时懒加载）。测试照项目惯例写 `frontend/scripts/test-*.mjs`（node:assert）。

**Spec:** `docs/superpowers/specs/2026-11-09-nianjing-design.md`

## Global Constraints

- 经文和拼音只取已校对来源：`src/data/sutras/*.js`（7 部）和 `D:\document\念佛板块\text\{wangshengzhou,liuzi,shixiaozhou,yaoshi-zhenyan,yaoshijing}.json`；不用拼音库生成经文拼音。
- 不上传任何音频或识别文字；识别全在本机。
- 对不上时位置不动；`feed()` 返回 -1。
- Cloudflare Pages 单文件 < 25MB。
- 木鱼固定节拍，复用 `createWoodblock()`（`src/utils/nianfo.js`）。
- 页面文案不出现内部用词；免费、不用注册。

## Review Focus

- 一行经文汉字数和拼音音节数不一致（拼音错位）→ 数据测试逐行断言相等（Task 1）。
- 识别出一串完全无关的字（旁人说话、电视声）→ 位置不动（Task 2 测试 `ignores unrelated speech`）。
- 用户重读上一句 → 位置往回退到重读处，而不是卡死或跳到后面（Task 2 `handles re-reading`）。
- 模型下载失败 / 拒绝麦克风 / 浏览器无 WASM → 显示原因并切到「自动」（Task 3 `fallback` 手测清单）。
- 手机转屏（竖↔横）→ 当前句不丢（Task 4 手测清单）。

### Task 2: 位置对齐器

**Files:** Create `frontend/src/utils/sutraAligner.js`；Test `frontend/scripts/test-sutra-aligner.mjs`

**Interfaces:**
- Consumes: `toUnits` 的 `chars[].py`
- Produces: `fuzzy(py: string) => string`（去声调，zh/ch/sh→z/c/s，n→l 开头，ng→n 结尾）；`class SutraAligner { constructor(scriptPys: string[][] /* 每个字的可接受读音 */); pos: number; seek(i: number); feed(hypPys: string[]) => number /* 新 pos 或 -1 */ }`。参数与 Java 版一致：TAIL 10、LOOK_BACK 12、LOOK_AHEAD 60、相同 2 / 韵母同 0.5 / 不同 -1.2、跳识别 -1、跳经文 -0.8、距离罚 0.03、阈值 `max(2.5, 0.9*m)`。

- [ ] 测试 `advances on exact reading`、`tolerates 2 wrong chars in 10`、`ignores unrelated speech`（返回 -1，pos 不变）、`handles re-reading`、`polyphone accepted`（经文「般」读音集 [bo, ban] 时识别出 ban 也算）。
- [ ] 实现、通过、提交。

**Interfaces:**
