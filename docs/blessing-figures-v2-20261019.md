# 12 blessing figures — regenerated set

All twelve source images were generated in the user-selected ChatGPT web conversation, visually reviewed, and converted from transparent PNG to 1024×1536 RGBA WebP. No existing Buddha images or symbolic still lifes are reused. Duplicate peace-guardian generations were rejected; the house guardian was regenerated separately.
